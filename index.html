    AI-Erkennung

    Erzeugt aus dem geladenen Bild bzw. der PDF-Seite ein Topo. Der Aufruf läuft direkt aus deinem Browser zum Modell — blockiert ein Gateway das (CORS), springt automatisch der lokale Proxy ein, sofern er läuft (npm start).

    Einstellungen

    Der Key wird nur im localStorage dieses Browsers gespeichert und ausschließlich an den angegebenen Endpoint gesendet. Auf gemeinsam genutzten Rechnern besser einen eigenen Proxy verwenden.
